📦 资源批量导入生成器

➕ 添加资源

💡 使用说明：
1. 填写资源信息后点击「添加到列表」
2. 可重复添加多个资源
3. 点击「生成JSON」生成导入格式
4. 复制JSON → 管理后台「批量导入」粘贴 → 导入

⚡ 快速操作：可使用模板快速填充
📋 点击使用模板：AI短剧课程示例

📋 JSON 输出

已添加：0 条资源 VIP：0 | 免费：0 
// 添加资源后会在这里生成JSON格式
// 可直接复制到管理后台「批量导入」中使用

[
  {
    "title": "资源标题",
    "desc": "简短描述",
    "downloadLink": "https://...",
    "price": 99,
    "isVip": true
  }
]
📌 字段说明：
• title - 必填，资源标题
• desc - 列表页显示的简短描述
• downloadLink - VIP用户看到的下载链接（每个资源不同！）
• price - 价格，0或空表示免费
• isVip - 是否需要VIP才能下载
• detail - 详情页详细内容
• features - 特点数组
• tag - 分类标签
• hot - 是否热门推荐
• cover - 封面emoji图标
